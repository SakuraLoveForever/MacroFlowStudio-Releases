# MacroFlow Studio

MacroFlow Studio 是 Windows 键鼠录制与自动化工具。你可以录制操作、编辑脚本，用图像或离线 OCR 判断状态，并用工作流串联任务。

## 安装

适用于 64 位 Windows 10（1809 或更新版本）和 Windows 11。安装时需要联网，应用自带离线 OCR 模型。

1. 打开[最新版本](https://github.com/SakuraLoveForever/MacroFlowStudio-Releases/releases/latest)，在 Assets 中下载 `MacroFlowStudio_Setup_*_win64.exe`。
2. 双击安装包，选择安装位置和是否创建桌面快捷方式。安装向导会从官方 PyPI 下载并校验所需运行库。
3. 安装完成后，从所选目录打开 `MacroFlowStudio.exe`，也可以使用开始菜单或已创建的桌面快捷方式。

## 使用

在「脚本编辑」中绑定目标窗口，按 `F8` 开始或结束录制，保存后按 `F9` 回放。按 `F12` 停止。在「工作流」里可以按顺序运行多个脚本。

## 更新和卸载

更新前备份自己创建的脚本、工作流和识图模板。更新时使用新版安装包。可在 Windows 的「已安装的应用」中卸载 MacroFlow Studio。

GitHub 自动生成的 Source code 归档只含对应版本的使用说明。实际安装包位于单独上传的 Release 附件中。
